# 答案

## 2025-10-23

1. `null` 表示一个空的对象，转换成数值时为 `0`，布尔值为`false`，而 `undefined` 表示未定义的原始值，转换成数值时为 `NaN`,布尔值为`false`，且 `typeof null` 为 `object`，`typeof undefined` 为 `undefined`。
2. JavaScript 使用 64 位双精度浮点数表示所有数字,部分十进制小数（如 0.1 和 0.2）无法被二进制精确表示.
3. 沿着对象的原型链查找构造函数的 `prototype`。
4. `isNaN` 会将参数转换为数值后进行判断，而 `Number.isNaN` 不会进行类型转换，直接判断参数是否为 `NaN`。
5. `==` 会进行类型转换后比较，而 `===` 不进行类型转换，直接比较值和类型是否相同。

## 2025-10-24

1. 创建一个空对象，将这个空对象的原型指向构造函数的 prototype, 将构造函数的 this 指向这个对象，并执行函数，返回结果，如果没有返回值则返回这个对象。
2. object 只能以字符串或者 symbol 作为 key，map 的 key 是任意类型，map 可迭代，有 size 直接获取长度，创建的 map 不会包含任何属性，key 是有顺序的，wekmap 的 key 只能是对象，是弱引用，不能枚举，不会影响垃圾回收
3. ESModule 是静态的，在编译时确认依赖关系，输出是值的引用，commonjs 时动态的，在运行时加载，输出值得浅拷贝，由于 ESModule 是静态的，所以可以进行静态分析，例如 eslint 或者 tree shaking
4. this 指运行时绑定的上下文引用，取决于函数的调用方式和位置，而不是函数定义位置，可以通过 call、apply、bind 改变 this 指向
5. 由内部作用域访问外部作用域的变量、函数或者参数时闭包就产生了，
